# Miles & Memories

A travel diary website featuring two destinations: the Maldives and Germany.

## Project files

- `website/index.html` — website content and navigation
- `website/style.css` — colours, fonts and page layout
- `website/images/` — photographs used in the website

## Technologies

- HTML
- CSS
- Bootstrap 5

## Running the website

Open `website/index.html` in a web browser. An internet connection is required to load the Bootstrap files.
